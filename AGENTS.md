# AGENTS.md

## What this is
`mdns-filoxy` is a small, single-package Python CLI: an mDNS filter proxy. It browses mDNS services on
`--source-interface` and re-registers them on `--dest-interface` so devices that can't be reached directly stay
discoverable. Entry point: `mdns_filoxy.main:entry_point` (`src/mdns_filoxy/main.py`).

## Commands (use Hatch)
There is typically no `python`/`pip` on PATH here; let Hatch manage the environment.
- All tests: `hatch test`
- Single test: `hatch test tests/test_listener.py::test_name`
- Coverage: `hatch test --cover` (writes `.coverage`)
- Lint / format: `hatch run lint:check` / `hatch run lint:format` (`hatch run lint:format-check` to verify)
- Typecheck (src + tests): `hatch run types:check`

CI (`.github/workflows/ci.yml`) runs tests, lint, typecheck and a `hatch build` smoke check on pushes and PRs to
`master`. `.github/workflows/python-publish.yml` triggers on a version tag push (`X.Y.Z`, no `v` prefix): it builds,
creates the GitHub Release, then publishes to PyPI via OIDC trusted publishing. Run the checks locally before
finishing.

## Non-obvious constraints in `main.py`
- `ServiceListener` callbacks run on zeroconf `ServiceBrowser` threads. An unhandled exception kills that browser
  thread and silently stops proxying that service. Keep the `try/except` guards around the callback bodies.
- The destination `Zeroconf` raises `ServiceNameAlreadyRegistered` if a name is registered twice. Sonos re-announces
  by firing `remove` then `add`, so you must `unregister_service()` before re-registering. `ProxyRegistry` enforces
  this — keep add/remove symmetric and idempotent.
- `get_service_info()` can return `None` (timeout); guard it before registering.
- A single `ProxyRegistry` is shared by all listeners; its lock is intentional (callbacks run on multiple threads).

## Conventions
- Ruff rules are pinned in `[tool.ruff.lint] select` because newer ruff defaults expanded massively; add rule codes
  there deliberately rather than relying on defaults. Line length 120, single quotes.
- `src/mdns_filoxy/_version.py` is generated by hatch-vcs and gitignored — never edit or commit it.
- Tests live in `tests/`, use fakes instead of real network sockets, and are type-checked too
  (`cast(Zeroconf, fake)` in tests is deliberate).
